# 🎵 网页音乐播放器

一个现代化的网页音乐播放器，支持双播放模式（外链模式/API模式），采用原生前端技术栈构建，支持主题切换、歌单管理、响应式设计等功能。

---

## 📖 项目概述

### 开发历程

本项目从零开始构建，经历了完整的软件开发流程：

**第一阶段：基础架构搭建**
- 采用 HTML5 语义化标签构建页面结构
- 使用 CSS3 实现响应式设计和主题切换系统
- 通过原生 JavaScript 实现所有交互功能

**第二阶段：核心功能实现**
- 集成网易云音乐外链播放器作为播放核心
- 实现歌单管理系统，支持歌曲切换和状态同步
- 开发主题切换功能，支持浅色/深色双主题

**第三阶段：用户体验优化**
- 添加上一首/下一首控制按钮
- 实现歌单展开/收起功能，优化界面空间利用
- 完善加载状态提示和错误处理机制

**第四阶段：架构重构**
- 将歌曲数据从硬编码迁移到 JSON 文件
- 实现数据与逻辑分离，提升代码可维护性
- 优化事件处理机制，使用事件委托模式

**第五阶段：双播放模式升级**
- 新增 API 模式，通过网易云音乐 API 获取音频 URL
- 实现播放模式切换功能，支持外链模式/API模式切换
- 创建本地 Express 服务器，提供 API 代理和静态文件服务
- 优化播放控制逻辑，切换模式时自动暂停播放

### 开发哲学

本项目遵循以下开发原则：

1. **纯前端技术栈** - 不依赖任何外部框架，使用原生 HTML/CSS/JavaScript
2. **数据驱动设计** - 采用 JSON 存储歌曲数据，便于扩展和维护
3. **用户体验优先** - 所有交互都经过精心设计，提供流畅的操作体验
4. **响应式适配** - 确保在各种设备上都能正常使用
5. **模块化架构** - HTML/CSS/JS 分离，代码结构清晰
6. **灵活播放** - 支持多种播放方式，应对不同场景需求

### 克服的技术挑战

- **跨域 iframe 限制** - 网易云音乐播放器是跨域 iframe，无法直接监听播放事件
- **file:// 协议限制** - 本地直接打开 HTML 时 fetch 请求会被浏览器拦截
- **API 访问限制** - 网易云音乐 API 需要特定请求头才能正常访问
- **版权限制处理** - 部分歌曲受版权保护，需要提供友好的错误提示
- **模式切换同步** - 切换播放模式时需要确保旧播放器停止播放

## ✨ 功能介绍

### 核心功能

#### 1. 双播放模式

播放器支持两种播放模式，可随时切换：

**外链模式**（默认）
- 使用网易云音乐 iframe 外链播放器
- 播放器自带完整控制功能（播放/暂停、进度条、音量等）
- 适合大部分歌曲播放

**API 模式**
- 通过网易云音乐 API 获取音频直接链接
- 使用 HTML5 Audio 标签播放
- 不依赖 iframe，更轻量灵活
- 可通过自定义按钮控制播放

**模式切换特点**：
- 点击右上角按钮即可切换
- 切换时自动暂停当前播放，避免双音轨
- 播放模式偏好保存到 localStorage
- 播放/暂停按钮仅在 API 模式下显示

#### 2. 音乐播放

**外链模式播放**：
- 集成网易云音乐外链播放器
- 自动加载并播放歌曲
- 支持播放器加载状态监测

**API 模式播放**：
- 通过本地服务器代理获取音频 URL
- 使用 HTML5 Audio 原生播放
- 支持播放/暂停控制按钮
- 无版权歌曲显示友好提示

#### 3. 歌单管理
- 支持多歌曲切换播放
- 歌单默认收起，点击箭头展开
- 当前播放歌曲高亮显示
- 点击歌单项立即切换播放

#### 4. 播放控制
- **上一首按钮** - 切换到上一首歌曲，支持循环播放
- **下一首按钮** - 切换到下一首歌曲，支持循环播放
- **播放/暂停按钮** - 仅在 API 模式下显示
- 按钮颜色跟随主题变化
- 平滑的悬停动画效果

#### 5. 主题切换
- **浅色主题** - 白色背景，深色文字，适合日间使用
- **深色主题** - 深色背景，浅色文字，适合夜间使用
- 主题偏好自动保存到 localStorage
- 页面刷新后保持用户选择的主题
- 太阳/月亮 SVG 图标平滑切换

#### 6. 响应式设计
- **桌面端** (1025px+) - 大屏优化布局
- **平板端** (769px-1024px) - 中等屏幕适配
- **移动端** (480px-768px) - 小屏优化
- **超小屏** (<480px) - 极小屏适配

### 用户体验优化

- **加载状态提示** - 显示加载动画，避免用户等待焦虑
- **错误处理机制** - 网络异常或无版权时显示友好提示
- **操作反馈动画** - 所有交互都有平滑过渡效果
- **模式切换体验** - 切换模式时自动清理旧播放器

## 💻 本地开发设置

### 前置要求

- 现代浏览器（Chrome、Firefox、Safari、Edge）
- Node.js 14.x 或更高版本
- npm 或 yarn 包管理器

### 方法一：使用 Node.js Express 服务器（推荐）

#### 步骤 1：安装依赖

```bash
# 进入项目目录
cd C:\Users\YourUsername\Desktop\my-music-player

# 安装依赖
npm install
```

#### 步骤 2：启动服务器

```bash
# 启动 Express 服务器（同时提供 API 和静态文件服务）
node server.js
```

服务器启动后会显示：
```
服务器运行在 http://localhost:3000
```

#### 步骤 3：访问应用

打开浏览器，访问：
```
http://localhost:3000
```

#### 步骤 4：停止服务器

在命令行窗口按 `Ctrl + C` 停止服务器。

### 方法二：使用 Python 本地服务器（仅静态文件）

> ⚠️ 注意：此方法只能使用外链模式，无法使用 API 模式。

```bash
python -m http.server 8080
```

### 方法三：使用 VS Code Live Server 插件

> ⚠️ 注意：此方法只能使用外链模式，无法使用 API 模式。

1. 安装 Live Server 插件
2. 右键点击 `index.html`
3. 选择 "Open with Live Server"

### ⚠️ 重要提示

**不要直接双击 `index.html` 打开！**

如果直接双击 HTML 文件打开（使用 `file://` 协议），浏览器会拦截 `fetch` 请求，导致歌曲数据加载失败。必须通过 HTTP 服务器访问。

**API 模式必须使用 Node.js Express 服务器！**

## 🎼 歌曲管理说明

### 重要提示

**所有歌曲信息存储在 `songs.json` 文件中！**

### 当前歌曲列表

```json
[
  {
    "id": "2154219378",
    "name": "はいよろこんで",
    "artist": "こっちのけんと",
    "playlistName": "歌曲一"
  },
  {
    "id": "3348197008",
    "name": "ブレインロット",
    "artist": "脑蚀",
    "playlistName": "歌曲二"
  }
]
```

### 如何添加新歌曲

#### 步骤 1：获取歌曲 ID

1. 访问 [网易云音乐官网](https://music.163.com/)
2. 搜索目标歌曲
3. 进入歌曲详情页面
4. 从 URL 中提取歌曲 ID（如 `https://music.163.com/#/song?id=2154219378` 中的 `2154219378`）

#### 步骤 2：添加到 JSON 文件

打开 `songs.json` 文件，添加新的歌曲对象：

```json
[
  {
    "id": "2154219378",
    "name": "はいよろこんで",
    "artist": "こっちのけんと",
    "playlistName": "歌曲一"
  },
  {
    "id": "你的歌曲ID",
    "name": "歌曲名称",
    "artist": "歌手名",
    "playlistName": "歌曲三"
  }
]
```

### 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| `id` | 网易云音乐歌曲 ID | `"3348197008"` |
| `name` | 歌曲名称 | `"ブレインロット"` |
| `artist` | 歌手名 | `"脑蚀"` |
| `playlistName` | 歌单显示名称 | `"歌曲三"` |

### JSON 格式注意事项

1. **数组结构** - 所有歌曲对象必须包含在 `[ ]` 中
2. **对象分隔** - 每个对象之间用 `,` 分隔（最后一个对象后不加逗号）
3. **字段格式** - 所有字段值必须用双引号 `"` 包裹
4. **编码格式** - 文件必须使用 UTF-8 编码（支持中文和日文）
